# Дорога

Браузерная 3D-игра: выбор машины в гараже → выезд на трёхполосную трассу → бесконечная езда. Дорога и окружение генерируются процедурно.

ТЗ: https://claude.ai/artifact/V7cgKGnhUsB4akNg65iz2G

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run shot     # снимки кадров в shots/ (headless Chromium из ~/.cache/ms-playwright)
```

Служебные параметры URL: `?q=low|medium|high` — качество графики, `?seed=N` — трасса,
`?shot=garage|intro|drive&s=…&v=…&lane=…` — детерминированный кадр для снимков.

## Управление

← → / A D — полоса, ↑ / W — газ, ↓ / S / пробел — тормоз, C — камера, Esc / P — пауза.
На телефоне: касание левой/правой половины экрана или свайп — полоса, педали внизу.

## Устройство

- `src/road.ts` — бесконечная ось дороги (повороты, уклоны, виражи), чанки по 96 м: асфальт, щебень, кюветы, рельеф, отбойники; дальний рельеф вокруг машины.
- `src/textures.ts` — процедурные текстуры асфальта (разметка, колея, трещины, латки), травы, щебня.
- `src/car.ts` — процедурная машина: кузов по сечениям, стёкла, фары и фонари по поверхности, колёса с дисками и тормозами.
- `src/drive.ts` — сцена езды: небо, солнце с тенями, управление, камера и заставка выезда.
- `src/garage.ts` — гараж с подиумом. `src/render.ts` — рендер, свечение, цветокоррекция, пресеты качества.
