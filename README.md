# ОСАГО the game

Браузерная 3D-игра о поездках по процедурной трёхполосной трассе. Выберите машину в гараже, обгоняйте трафик и продержитесь весь страховой год: 365 игровых дней, смена сезонов и новый полис примерно каждые три минуты езды.

[Играть](https://72.56.126.248:8093/) · [Прототипы транспорта](https://72.56.126.248:8093/proto.html) · [Исходное ТЗ](https://claude.ai/artifact/V7cgKGnhUsB4akNg65iz2G)

## Поездки и гараж

- **Машины игрока.** «Комета GT», «Кедр 4×4» и «Простор 7» различаются разгоном, максимальной скоростью, управлением и объёмом бака.
- **Маршрут.** Вдоль трассы сменяются побережье, города, пригороды, засушливые участки и леса. Машина электрическая: заряд батареи тратится на километры, в автосервисе можно зарядиться и восстановить кузов. Для съезда заранее перестройтесь в правую полосу.
- **Страховка и прогресс.** ОСАГО покрывает игровой ущерб другим машинам, КАСКО позволяет отремонтировать свою. С ОСАГО патруль останавливает один раз за год — инспектор сверяет документы и желает счастливого пути; без полиса проверок четыре и каждая заканчивается протоколом. На трассе можно подобрать монеты или батарейку в зелёном полупрозрачном шаре (+6 % заряда). Кошелёк и класс КБМ сохраняются в браузере.

## Управление

| Действие | Клавиатура | Сенсорный экран |
| --- | --- | --- |
| Перестроиться | `←` / `→` или `A` / `D` | Свайп или касание нужной половины экрана |
| Газ | `↑` или `W` | Потянуть кнопку «Газ» вверх. Выставленный газ сохраняется после отпускания |
| Тормоз | `↓`, `S` или пробел | Удерживать «Тормоз». Торможение сбрасывает газ |
| Пауза | `Esc` или `P` | Кнопка паузы |
| Переключить камеру | `C` | |

С крайней полосы можно перестроиться дальше на обочину. Машина на обочине плавно замедляется и слегка трясётся. Если справа открыт съезд к автосервису, перестроение ведёт на съезд.

С ноября по февраль дорога и обочины покрыты снегом. Покрытие влияет только на внешний вид, а у обочины иногда встречаются ёлки с гирляндами. Для служебного кадра без снега можно добавить `snow=0` к параметру `shot`.

## Прототипы транспорта

Откройте `/proto.html` или нажмите «Прототипы» в гараже. На странице доступны три машины игрока, седан, классический седан, грузовик, эвакуатор, лимузин, минивэн из трафика и патруль ДПС. Мотоцикл и мотоблок с повозкой доступны только в прототипах. Выбранную модель можно поворачивать мышью или свайпом, смотреть с четырёх заданных ракурсов и оставить во вращении. У «Кометы» можно переключать страховую ливрею.

Для прямой ссылки на модель добавьте `?car=kometa` или укажите другой идентификатор: `kedr`, `prostor`, `sedan`, `classic`, `limo`, `truck`, `tow`, `moto`, `van`, `tiller`, `police`. Параметр `yaw` задаёт исходный угол в радианах, а `livery=1` включает ливрею.

## Локальный запуск

Проект использует TypeScript, Three.js и Vite. Подходит Node.js 20.19+ в ветке 20 или Node.js 22.12+.

```bash
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Главная страница запускает игру, `/proto.html` открывает просмотр моделей.

Для общей таблицы рекордов запустите `npm run records` во втором терминале на Node.js 22.13+ (или 24). Vite проксирует `/api/records` к локальному серверу. По умолчанию результаты хранятся в `.doroga-records.sqlite`.

```bash
npm run build    # проверка TypeScript и сборка в dist/
npm run preview  # просмотр готовой сборки
npm run shot    # снимки кадров в shots/
```

Скрипт снимков использует установленный Chromium из кеша Playwright или путь из переменной `CHROME`. Для воспроизведения участка трассы используйте `?seed=1337`. Качество графики задаётся через `?q=low`, `?q=medium` или `?q=high`. Например, `?shot=drive&seed=1337&s=3500&v=90&lane=0` открывает кадр на отметке 3,5 км.

## Выкладка

На рабочем сервере Nginx обслуживает статическую сборку из `/var/www/doroga` по HTTPS на порту 8093. Ветка `main` репозитория `deploy` определяет версию сайта.

Для первой настройки серверу нужны Git, Node.js с npm, доступ к реестру npm, rsync, curl, Nginx и systemd. [Установщик](deploy/install.sh) собирает текущий коммит из `/root/doroga-bare.git`, включает наблюдение за веткой и сохраняет прежний хук как `post-receive.legacy` после первой успешной выкладки.

```bash
sudo bash /root/doroga/deploy/install.sh
```

Для следующих релизов используйте `git push deploy main`. Если выкладка прервётся, таймер повторит попытку. Служба записывает SHA в `/var/lib/doroga-deploy/revision` после того, как проверит ответ Nginx для `proto.html`. Журнал доступен через `journalctl -u doroga-deploy.service`.

При первом релизе с общей таблицей на уже настроенном сервере выполните `sudo bash deploy/install-records.sh` перед публикацией сайта. Установщик поднимает `doroga-records.service` и подключает `/api/records` через Nginx. Для обновления серверного кода таблицы запустите установщик снова. SQLite хранит результаты в `/var/lib/doroga-records/records.sqlite` между релизами.
