# Дорога

Браузерная 3D-игра о поездках по процедурной трёхполосной трассе. Выберите машину в гараже, обгоняйте трафик и доберитесь до финиша. Первая поездка длится 4 км. После каждого финиша дистанция следующей поездки увеличивается на 2 км.

[Играть](https://72.56.126.248:8093/) · [Прототипы транспорта](https://72.56.126.248:8093/proto.html) · [Исходное ТЗ](https://claude.ai/artifact/V7cgKGnhUsB4akNg65iz2G)

## Поездки и гараж

- **Машины игрока.** «Комета GT», «Кедр 4×4» и «Простор 7» различаются разгоном, максимальной скоростью, управлением и объёмом бака.
- **Маршрут.** Вдоль трассы сменяются побережье, города, пригороды, засушливые участки и леса. На заправках можно пополнить бак, в автосервисе — восстановить машину. Для съезда заранее перестройтесь в правую полосу.
- **Страховка и прогресс.** ОСАГО покрывает игровой ущерб другим машинам, КАСКО позволяет отремонтировать свою. Патруль может остановить водителя без ОСАГО. За финиш начисляются монеты. Кошелёк, статистика поездок и класс КБМ сохраняются в браузере.

## Управление

| Действие | Клавиатура | Сенсорный экран |
| --- | --- | --- |
| Перестроиться | `←` / `→` или `A` / `D` | Свайп или касание нужной половины экрана |
| Газ | `↑` или `W` | Потянуть кнопку «Газ» вверх. Выставленный газ сохраняется после отпускания |
| Тормоз | `↓`, `S` или пробел | Удерживать «Тормоз». Торможение сбрасывает газ |
| Пауза | `Esc` или `P` | Кнопка паузы |
| Переключить камеру | `C` | |

При выезде с вероятностью 25% дорога и обочины будут заснеженными. Покрытие сохраняется до конца поездки и влияет только на внешний вид. Для снимков можно задать `snow=1` для снежной трассы или `snow=0` для обычной. Служебные кадры без этого параметра используют обычную трассу.

## Прототипы транспорта

Откройте `/proto.html` или нажмите «Прототипы» в гараже. На странице доступны три машины игрока, седан, грузовик, мотоцикл, минивэн из трафика, мотоблок с повозкой и патруль ДПС. Выбранную модель можно поворачивать мышью или свайпом, смотреть с четырёх заданных ракурсов и оставить во вращении. У «Кометы» можно переключать страховую ливрею.

Для прямой ссылки на модель добавьте `?car=kometa` или укажите другой идентификатор: `kedr`, `prostor`, `sedan`, `truck`, `moto`, `van`, `tiller`, `police`. Параметр `yaw` задаёт исходный угол в радианах, а `livery=1` включает ливрею.

## Локальный запуск

Проект использует TypeScript, Three.js и Vite. Подходит Node.js 20.19+ в ветке 20 или Node.js 22.12+.

```bash
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Главная страница запускает игру, `/proto.html` открывает просмотр моделей.

```bash
npm run build    # проверка TypeScript и сборка в dist/
npm run preview  # просмотр готовой сборки
npm run shot    # снимки кадров в shots/
```

Скрипт снимков использует установленный Chromium из кеша Playwright или путь из переменной `CHROME`. Для воспроизведения участка трассы используйте `?seed=1337`. Качество графики задаётся через `?q=low`, `?q=medium` или `?q=high`. Например, `?shot=drive&seed=1337&s=3500&v=90&lane=0` открывает кадр на отметке 3,5 км.

## Выкладка

На рабочем сервере Nginx обслуживает статическую сборку из `/var/www/doroga` по HTTPS на порту 8093. Ветка `main` репозитория `deploy` определяет версию сайта.

Для первой настройки серверу нужны Git, Node.js с npm, доступ к реестру npm, rsync, curl, Nginx и systemd. [Установщик](deploy/install.sh) собирает текущий коммит из `/root/doroga-bare.git`, включает наблюдение за веткой и сохраняет прежний хук как `post-receive.legacy` после первой успешной выкладки.

```bash
sudo bash /root/doroga/deploy/install.sh
```

Для следующих релизов используйте `git push deploy main`. Если выкладка прервётся, таймер повторит попытку. Служба записывает SHA в `/var/lib/doroga-deploy/revision` после того, как проверит ответ Nginx для `proto.html`. Журнал доступен через `journalctl -u doroga-deploy.service`.
